# Aggregated tables

One CSV per table or headline number of the paper. `n/r` = not recorded in the session files.
Counts are recomputed from `../ratings/` by `../scripts/analyze.py` (t1, t3, t4, t5 (panel part), t7).
t6 and the model-flag counts in t5 come from session records that are not released (see top-level README).
The module C6 scores of the dry-runs (+40 % and +44 %) and the earlier researcher's count of process elements (19 of 24) are deliberately not tabulated: the paper explains why they are not used as evidence.
